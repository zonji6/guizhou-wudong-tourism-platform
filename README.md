# 贵州乌冬文旅综合服务平台

面向项目答辩的本机可操作原型，围绕“衣食住行 + 社区分享 + 平台管理”构建，并以“苗族文化茶旅体验”为核心差异化场景。

## 项目目标

游客可通过微信小程序或 PC 网页端浏览资源、向 AI 助手咨询并规划行程、提交预约；运营人员可在后台管理内容和订单，并查看脱敏的 AI 执行轨迹。

## 计划技术栈

原生微信小程序、Vue 3、Java Spring Boot、Python FastAPI、LangGraph、DeepSeek、阿里云百炼 Embedding、MySQL、Redis Stack、WebSocket、LangSmith。
