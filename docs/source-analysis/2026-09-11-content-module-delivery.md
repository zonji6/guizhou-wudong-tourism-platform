## 本机图片准备

Word 内 228 张图片全部保留原媒体编号，统一转换为 JPEG，最长边 1400 像素；另生成最长边 600 像素的缩略图。共 456 个本机文件，约 30 MB。

```powershell
.\scripts\prepare-content-media.ps1 -SourceDocument 'C:\Users\zonji\Desktop\乌东衣食住行.docx'
```

生成位置为 `web/public/images/wudong-content/`。例如，Word 的 `image208.png` 对应：

- 正图：`/images/wudong-content/image208.jpg`
- 缩略图：`/images/wudong-content/image208-thumb.jpg`

不按提取清单行号重新编号；原始 `.png`、`.jpg`、`.jpeg` 后缀均统一为 `.jpg`。缺少派生图时，`start-demo.ps1` 会尝试从当前用户桌面或下载目录找到该 Word 并生成。

素材仅供本机演示，版权授权尚未核实，文件已加入 Git 忽略规则，不上传公开仓库。新电脑克隆代码后需要提供本地 Word 并运行脚本。

微信开发者工具使用本机 Web 的图片地址，避免将全套资料塞入小程序包。`127.0.0.1` 仅适合本机开发者工具，不代表支持真机访问。
