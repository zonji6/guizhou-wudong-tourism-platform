# 乌东首页「入寨长卷」与自然动效设计

**状态：** 待用户书面审阅  
**范围：** Web 首页卷帘、五联到正文的雾气转场、沿溪叙事背景，以及“一叶同行”入口动效。

## 1. 设计目标

首页不再把茶、染、山水、人物和银饰做成互不关联的小图标，而要呈现一幅“远看是山水、近看有人文细节”的乌东入寨长卷。实景照片负责真实性，原创线描与动效只负责引导视线和建立气氛。

视觉节奏固定为：

```text
入寨长卷（静观）
→ 点击展卷（仪式）
→ 山水寨茶人五联（认识乌东）
→ 三层山雾（从观看进入行走）
→ 溪流串联的村寨章节（沿溪入寨）
→ 叶片随行并落入向导入口（开始规划）
```

## 2. 卷帘：一幅完整的乌东长卷

### 2.1 构图

左右卷帘共同组成一幅连续画面，中缝是展开轴线：

- 左卷上部为雷公山层叠山脊，中部是茶枝与采茶动作，下部转为蓝染布的水波纹。
- 右卷上部延续山脊，中部出现风雨桥与沿溪木楼，下部是染布女子的含蓄侧影。
- 女子不使用写实头像或“美女”标签，而以采茶/染布动作、发髻轮廓和少量银饰线光体现人物。
- 银饰只使用抽象圆片、流苏与涡旋反光，不宣称复刻某支系特定纹样。
- 中缝用一枚茶叶与银坠结合的锁扣收束，“点击这里”位于锁扣中心。

### 2.2 材质与层级

背景保留深青织物纵纹，外侧木轴保留老木质感。线描采用三种强度：溪石青用于山水远景、茶芽金用于茶枝和桥、银白用于人物银饰。默认低对比，鼠标靠近中央锁扣时，银光沿左右纹路向外传递一次。

### 2.3 展开动画

点击后先由锁扣产生一圈细水纹（约 240ms），随后线描向两侧轻微拉伸，卷轴整体向左右退出；五联按山、水、寨、茶、人依次出现。总时长约 1.5 秒。减少动态效果时只执行 180ms 淡出。

## 3. 五联后的三层山雾

雾层位于五联与正文的交界处，不覆盖首次门面，也不长期遮挡实景。它由三层组成：

1. 远雾：贴近山脚，宽而淡，缓慢上浮并降低透明度。
2. 中雾：横向穿过页面，边缘不规则，承担主要过渡。
3. 近雾：更白、更快，从视口下部掠过，短暂遮住溪流起点。

三层错开 120–180ms，整体约 1.6 秒完成。雾散后露出溪流起点，同时触发“一叶同行”首次出现。雾层始终 `pointer-events: none`。

## 4. 沿溪入寨：自然背景与内容路径

正文背景从纯米白改为层次很浅的山谷纸景：顶部保留远山剪影，左右有低透明度树冠与茶叶投影，局部出现苔石颗粒。不能使用高对比装饰干扰正文。

一条 SVG 溪流从页面上方中央进入，以 S 形穿过三个章节：

- 在“沿溪入寨”章节靠近溪涧照片。
- 转向“一寨一谷”的航拍图，形成村寨空间连接。
- 最后流向“人在寨中”和衣食住行服务节点。

溪流由半透明宽水面、内侧亮线和少量涟漪组成；滚动进入时亮线沿路径缓慢显现。照片不再像两块独立矩形，而以错位圆角、轻投影和石岸边框嵌在河道两侧。章节文字保持足够留白。

服务入口仍是四个真实导航按钮，但改为溪边“停靠点”：石形底座、小型题签、连接溪流的短支线。它们不是平均分布的标准卡片墙。

## 5. 一叶同行与水纹动效

“一叶同行”从普通圆形按钮改为真正的茶叶轮廓，由 CSS/SVG 叶片与一条叶脉构成：

- 雾散时，一枚叶片从溪流起点沿短弧线漂落到右下角，过程约 1.2 秒。
- 停驻后仅做 2–3px 的低频漂浮和轻微转角，不持续旋转。
- 悬停或键盘聚焦时，叶片下方产生两圈水纹，并显示“一叶同行”。
- 点击时水纹扩散一次，同时平滑滚动到乌东向导区域。
- 页面滚动接近向导区域后，叶片缩小并降低存在感，避免重复抢占视觉中心。
- 减少动态效果时取消漂落、漂浮和水纹，只静态淡入并保留可见焦点。

## 6. 组件边界

- `ScrollGate.vue`：增加完整长卷场景与中央叶形银坠锁扣。
- `WudongJourney.vue`：增加三层雾、溪流 SVG、章节场景标识与自然装饰层。
- `LeafGuide.vue`：增加叶片、叶脉、水纹和可见文字结构。
- `HomePage.vue`：只负责向 LeafGuide 传递“出现”和“接近向导”的状态，不承载绘图细节。
- `style.css`：实现全部视觉与动效；不引入图片生成资产、动画库或第三方依赖。

五联与单屏探景沿用已经通过审查的实现，本次只处理四张截图指出的缺口。

## 7. 响应式与可访问性

- 桌面端完整呈现连续长卷、三层雾和 S 形溪流。
- 移动端保留卷帘代表性元素，溪流退化为左侧纵向水线，避免复杂 SVG 挤压内容。
- 所有装饰元素均 `aria-hidden="true"`，不进入阅读顺序。
- 叶片入口仍是原生按钮，具备可见焦点和“打开乌东向导”标签。
- 所有动画只改变 `transform`、`opacity` 或 SVG 描边进度；核心内容在动画关闭后保持可访问。

## 8. 用户可见验收

1. 未开卷时可辨认山水、茶枝、蓝染、女子侧影和银饰，而不是只有重复几何纹样。
2. 点击中央叶形银坠后，水纹、卷轴退出和五联出现形成连续动作。
3. 五联下滑时有明显但不遮挡内容的前、中、后三层雾气。
4. 正文可看见一条自然溪流将三组照片、文字和服务入口串联起来。
5. 叶片随雾散出现，漂落到右下角；悬停有水纹，点击平滑进入向导。
6. 页面没有新增与乌东无关的通用图标、人物写实画像或未经核验的文化断言。

## 9. 验证约定

遵循项目约定，本次不新增自动化测试，不运行全量测试或回归测试。实现后只进行代码范围检查和用户可见的浏览器人工验收。
