# 乌东首页「苗纹护卷」细化设计

**状态：** 待用户审阅
**范围：** 仅调整 Web 首页开卷、五联实景和五联点击后的探景层；不改变服务、AI、后台或小程序的功能边界。

## 1. 设计原则

乌东的真实性来自实景照片，而非一张泛苗族概念图。视觉元素仅承担“入寨”与“章节分隔”的作用：木构的温度、织锦的手工感、银饰的微光、山路与溪水的方向感共同出现，但不把未经核验的特定纹样当作文化事实。

开卷前无雾，用户一眼能读到卷轴全貌；雾只保留在继续下滑后的山景转场。动效只使用 `transform` 与 `opacity`，并尊重 `prefers-reduced-motion`。

## 2. 首次进入：苗纹护卷

闭合卷轴以湿山深绿为底，叠加如下低对比层次：

1. 两端深褐木轴与不规则木纹，表现吊脚楼木构的材质感。
2. 木轴内侧是靛青织锦边，使用抽象水波、蝶翼、叶脉与回旋线，不复制或命名具体苗绣图腾。
3. 局部茶芽金细线与少量银白亮点，在鼠标靠近“点击这里”时依次亮起，模拟银饰反光，不使用闪烁。
4. 中央题字为“走进雷公山半山的乌东苗寨”；唯一操作仍为“点击这里 / 开启画卷”。

点击后左右木轴向外退场，织锦边先于实景淡出；五联按照山、水、寨、茶、人的顺序，以 70–90ms 的轻微错位显现。总时长约 1.4 秒，减少动态效果时压缩为 180ms 的淡入。

## 3. 开卷后：五扇寨门

五联不再贴满浏览器边缘，而是置于雾纸白页面上的木构画框内：桌面端最大宽度约 1440px、页面左右保留 4–6vw 呼吸区。画框顶部、两端只使用细小茶芽金分隔与抽象纹样，避免成为喧宾夺主的贴图。

| 场景 | 尺寸与光影 | 在地叙事 |
| --- | --- | --- |
| 山 | 标准宽度；冷白雾光由左上切入 | 湿润中山与挑担行路 |
| 水 | 标准宽度；桥下保留柔和反光 | 风雨桥、溪水与入寨路径 |
| 寨 | `1.3×` 宽度；山脊处暖日光展开 | 乌东苗寨的空间总览，保留原图文字 |
| 茶 | 标准宽度；茶叶方向有轻叶影 | 采茶动作与茶旅体验 |
| 人 | 标准宽度；从右侧落入火塘铜色温 | 自然的长幼互动与寨里温度 |

五幅之间留 6–8px 深绿窄缝，底部以场景题签、短副题收束。默认不自动改变宽度；悬停、键盘聚焦时仅将当前幅舒展少量，其他画幅温和收缩。用户点击或按回车才进入探景。

## 4. 探景：一页短章

桌面端探景为固定画幅对话层，最大尺寸 `min(92vw, 1500px)` × `min(78vh, 720px)`，完全适配可见高度：

- 左侧约 58% 是实景图；图内只显示景名题签。
- 右侧约 42% 是场景、短标题、最多三行正文与一个主行动；按钮固定在内容结尾。
- 关闭按钮固定在右上，遮罩点击和 `Escape` 都可返回，且不丢失首页位置。
- 对话层和内部内容均禁止桌面端纵向滚动；文字以截断保障单屏。
- 小屏退化为纵向内容，但维持紧凑信息量，不影响内容可读性。

## 5. 要修改的实现边界

- `web/src/components/home/ScrollGate.vue`：补充卷轴的文化纹理层和打开时序，不更改开卷状态逻辑。
- `web/src/components/home/FiveSceneHero.vue`：增加画框、题签与场景光影语义类，不替换已确认的实景素材。
- `web/src/components/home/SceneExplorer.vue`：增加信息区结构，以保证桌面端单屏完成阅读与行动。
- `web/src/style.css`：新增/替换上述三部分的响应式样式和减少动态效果降级。

不修改路由、`scenes.js` 的内容、资源详情页、后端接口或小程序。

## 6. 用户可见验收

1. 闭合卷轴可看出木轴、织锦边和低调的苗寨文化细节，但视觉中心仍是点击入口。
2. 开卷后五联有左右留白、木构画框、窄缝与不同光影，中心“寨”稍宽。
3. 点击任一画幅，桌面端探景无内部滚动条，图、短文和行动按钮同时可见。
4. 山、水、寨、茶、人原有实景及“寨”图中的乌东文字继续保留。
