# 贵州乌东文旅平台答辩演示流程

## 演示口径

本次展示的是本机可操作原型，不是已上线系统。未核验的商家、价格、库存和内容均为演示数据；地点与公开授权尚未核验的照片仅用于本机演示。

- 配置有效 `DEEPSEEK_API_KEY` 后，才能把向导结果称为实时模型生成。
- 未配置 DeepSeek 或实时调用失败时，先展示错误/降级提示；只有用户主动点击“查看演示结果”后，才进入演示模式。静态结果不得称为 DeepSeek 回答。
- 云端 Embedding 服务尚未提供时，检索标签必须是“关键词资料（演示）”，不得称为向量 RAG。
- 未配置 LangSmith 时，不宣称已经上传 Trace；后台只展示本机脱敏运行摘要，不展示模型思维链、联系人原文或 API Key。

## 演示前准备

1. 根据答辩需要，在本机环境文件中配置 DeepSeek；云端 Embedding 与 LangSmith 未提供时保持未配置，并按上面的降级口径讲解。
2. 按当前项目说明启动本机依赖、Java 服务、Python 服务和 Web；在微信开发者工具中打开 `miniprogram` 目录。
3. 准备一个带非空业务 `serviceId` 的服务推荐，以及可在后台检索到的演示订单。不要使用模型临时文本或页面标题代替 `serviceId`。
4. 若任一实时能力未就绪，保留页面的真实错误状态并演示主动降级，不现场伪造成功。

> 本轮文档更新没有执行启动、构建、测试、浏览器检查或端到端验收。演示前仍需由用户按实际本机环境确认服务可用性。

## 六分钟答辩主链

### 1. 定位与点击开卷（30 秒）

打开 Web 首页，先说明平台服务的是“贵州乌东”，差异化主轴是当地山水、苗寨生活与茶旅体验。首次进入必须点击中央“点击这里 / 开启画卷”，由用户主动完成开卷；门面没有雾，不用自动播放代替仪式。

### 2. 山水寨茶人五联探景（50 秒）

卷轴打开后，按“山、水、寨、茶、人”浏览五联实景。重点打开“寨”和“茶”：寨景使用带“乌东苗寨”身份文字的实景，茶景聚焦采茶人物与动作。说明五张照片共同构成乌东印象，避免用一张泛贵州背景冒充当地全貌。

### 3. 下滑雾散、叶片与沿溪入寨（45 秒）

继续下滑，让短暂雾气在章节边界散开，“一叶同行”随后出现，再沿溪流、木楼和在地生活进入后续内容。这里的动画只承担转场，用户始终可以继续滚动，不把首屏全貌遮住。

### 4. 乌东向导连续追问（85 秒）

进入“乌东向导”，输入：

> 我想体验贵州乌东的苗族文化和茶旅，周末两个人，喜欢慢一点。

展示需求理解、知识检索、服务协同和行程生成等真实 WebSocket 阶段；未发生的阶段应显示跳过，不能用定时动画假装完成。接着围绕住宿或饮食再追问一次，说明同一 `thread_id` 保留上下文，上一版结果默认折叠。

展示结构化路线卡、服务卡和来源标题。若配置了 DeepSeek，可以说明这是实时模型结果；若页面处于演示模式，应主动说“这是同结构的静态演示结果”。若显示“关键词资料（演示）”，应说明当前没有云端 Embedding，而不是把它介绍成向量 RAG。

### 5. 真实 serviceId 与预约二次确认（65 秒）

从带真实 `serviceId` 的服务节点进入详情或预约。填写日期、人数、联系人和电话后，先创建 `PENDING_CONFIRMATION` 待确认信息，再在同一预约页核对并点击确认。强调：

- 纯模型文本、缺少 `serviceId` 的节点不会显示预约入口；
- AI 只能协助形成待确认信息，不能越过用户确认；
- 创建、读取或确认请求失败时保持错误状态，不生成本地伪订单；
- 答辩展示使用演示业务数据，不代表真实库存或支付。

### 6. 小程序五栏与“我的”（45 秒）

切换微信开发者工具，依次指向“首页｜游乌东｜向导｜寨里｜我的”五栏。展示移动端如何快速浏览资源、进入向导、查看寨里分享；把带真实服务节点的路线加入行程后，在“我的”查看当前行程和订单。说明小程序与 Web 共用业务接口，但采用工具优先布局，不复制桌面长卷。

### 7. 后台订单与脱敏摘要（40 秒）

进入管理后台，找到刚才的演示订单并展示状态；再查看对应的脱敏 AI 运行摘要，包括会话标识、节点、工具摘要、来源、耗时和最终状态。明确后台不展示思维链、完整联系人或密钥；未配置 LangSmith 时不声称存在云端 Trace。

## 收束表达

贵州乌东平台用真实地域叙事建立入口，用 Java 守住服务与订单事实，用 FastAPI 和 LangGraph 组织可见的 AI 协作过程，再用用户二次确认完成预约闭环。实时模型、关键词演示检索、静态演示卡片和规划中的后端 v2 必须分别说明，不能混为已经完成的 DeepSeek 或 RAG 能力。

## 用户验收清单

1. 新会话必须点击后才开卷；五联固定为“山、水、寨、茶、人”。
2. 下滑时雾只做转场，雾散后出现叶片，并能继续沿溪入寨。
3. 向导能连续追问，上一版折叠；演示模式与实时模式文案清楚。
4. 未配置云端 Embedding 时显示“关键词资料（演示）”。
5. 只有真实 `serviceId` 能进入预约，且预约必须二次确认。
6. 小程序底栏为“首页｜游乌东｜向导｜寨里｜我的”，“我的”能看到已加入行程和订单。
7. 后台能对应展示演示订单和脱敏摘要，不出现密钥、联系人原文或思维链。
