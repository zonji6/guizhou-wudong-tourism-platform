# 贵州乌冬文旅“衣食住行”综合服务平台需求文档

**版本：** 1.0
**用途：** 项目答辩演示原型
**产品名称：** 贵州乌冬文旅“衣食住行”综合服务平台

## 1. 项目背景

贵州乌冬拥有苗族文化、民宿、茶旅、餐饮、米酒、文创等文旅资源。游客缺少统一入口来了解资源、规划行程并完成预约；运营人员也缺少统一的内容、服务和订单管理入口。

本项目建设一个面向贵州乌冬文旅的综合服务平台，以“衣食住行 + 社区分享 + 平台管理”为业务主线，并提供 AI 文旅助手。

平台的首要差异化主轴是“苗族文化茶旅体验”：以茶园、制茶、品茶、苗寨生活与在地文化为核心体验，民宿、餐饮、文创和交通作为完整旅程的承接服务。平台不得退化为可替换任意地点名称的通用旅游模板。

## 2. 产品目标

在本机完成可操作的答辩原型，演示以下闭环：

~~~text
浏览贵州乌冬资源
→ 向 AI 助手描述需求
→ 获得行程、攻略回答或服务推荐
→ 提交并确认预约
→ 运营后台处理订单
→ 查看 AI 脱敏执行轨迹
~~~

本期用于验证产品与技术方案，不用于真实游客上线。

## 3. 用户角色

| 角色 | 终端 | 核心诉求 |
| --- | --- | --- |
| 游客 | 微信小程序、PC 网页端 | 浏览资源、获得攻略、规划行程、预约服务、查看订单 |
| 运营人员 | Web 管理后台 | 管理商家、服务、社区与知识内容；处理订单；查看运行摘要 |
| 答辩评委 | PC、微信开发者工具、后台 | 看到真实可操作闭环与 AI 编排链路 |

## 4. 功能需求

### 4.1 游客端

- 首页展示贵州乌冬特色和衣、食、住、行分类。
- 浏览民宿、餐饮、茶旅、文化体验、文创和套餐。
- 查看资源详情、价格、标签、推荐理由和预约入口。
- 浏览社区动态与攻略。
- 使用 AI 助手，获得个性化路线、资源推荐、攻略回答或补充问题。
- 看到“正在理解需求、正在检索资料、正在匹配资源、方案已生成”等状态。
- 提交预约，显式确认服务、日期、人数与联系人。
- 查看订单状态。

### 4.1.1 首个答辩主场景：苗族文化茶旅体验

游客输入“我想体验贵州乌冬的苗族文化和茶旅”，或从首页点击“苗族文化茶旅体验”。系统应展示茶园/村寨主视觉、茶旅体验资源、文化攻略和可组合的半日或两日行程；AI 助手应优先追问出行日期、人数和偏好，并返回“茶园体验—制茶/品茶—苗寨文化—餐饮/民宿承接”的路线卡片与来源。该场景必须贯穿 PC 端、小程序、RAG 知识库、预约订单和后台运行轨迹。

### 4.2 管理后台

- 管理商家和服务资源。
- 管理社区动态和贵州乌冬知识内容。
- 查看订单并更新订单状态。
- 查看脱敏 AI 运行摘要：会话标识、节点、工具摘要、知识来源、耗时和最终状态。

### 4.3 AI 文旅助手

AI 助手只服务贵州乌冬文旅业务，不包含差旅审批、企业制度、机酒供应链等阿里商旅业务。

| 用户需求 | 系统行为 |
| --- | --- |
| 点击“推荐民宿”“查看订单”等固定动作 | 直接查询业务数据，不调用模型 |
| 自由描述行程需求 | 提取日期、人数、预算和偏好；必要时追问；生成路线 |
| 询问贵州乌冬文化、攻略、茶旅等 | 检索贵州乌冬知识库后回答并附来源 |
| 想预约服务 | 生成待确认预约；仅用户在页面确认后创建正式订单 |

## 5. 关键流程

### 自然语言行程规划

~~~text
游客输入需求
→ 识别意图和缺失条件
→ 条件不足时追问
→ 检索贵州乌冬知识与服务资源
→ 生成结构化行程卡片
→ 游客查看推荐并进入详情或预约
~~~

### 预约订单

~~~text
选择服务
→ 填写日期、人数、联系人
→ 页面展示确认信息
→ 用户确认
→ 创建正式订单
→ 后台处理订单
→ 游客查看状态
~~~

### 知识问答

~~~text
游客提问
→ 检索贵州乌冬知识库
→ AI 基于检索资料回答
→ 显示答案与来源
→ 未找到资料时明确提示
~~~

## 6. 验收标准

1. PC 和小程序能浏览同一批贵州乌冬资源与社区内容。
2. AI 助手可完成一条自然语言行程请求，并返回带日程和资源推荐的卡片。
3. 固定按钮操作直接返回资源或订单结果。
4. 用户确认预约后，后台可查询并更新订单状态。
5. 知识回答带来源；资料不足时不编造事实。
6. 后台展示对应会话的脱敏节点、工具、来源、耗时和状态。
7. 模型、检索或工具不可用时显示降级提示，资源和订单功能不受影响。

## 7. 非目标

本期不实现真实支付、微信正式登录、真实库存、评价、即时聊天、地图导航、真机公网访问、对象存储、生产级权限、多实例部署或生产级告警。

## 8. 视觉与内容表现

整体视觉定位为“苗寨自然、温暖、有民族文化质感”。以贵州乌冬山林、茶园、村寨、民宿和在地体验的真实照片作为主视觉；采用茶绿、靛蓝、米白和暖铜色形成自然、温暖的层次。苗族纹样仅用于页签、分隔线、标题底纹等低频点缀，不得遮挡正文、价格、预约按钮或 AI 卡片内容。未核验的商家信息、价格、库存与图片必须明确标注为演示数据。
