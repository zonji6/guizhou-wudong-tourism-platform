# 贵州乌冬文旅平台项目进度

**项目目标：** 三天内完成可在本机操作、用于答辩的贵州乌冬文旅综合服务平台。

## 当前阶段

- 已完成：产品需求、技术架构、协作拓扑、本机演示说明，以及 Vue 门户/后台、微信小程序、Java v3 业务服务、Python 多 Agent 服务的演示主链集成。
- 当前可演示：USER 注册登录、同账号“我的”、商品/食/住三类下单、行程与草稿、社区、示意地图、ADMIN 独立登录与知识管理、AI 向导入口。
- 待接入：用户本机的 DeepSeek、百炼 Embedding 与 LangSmith API Key。

## 已明确的演示边界

- 核心场景是“苗族文化茶旅体验”：茶园体验、制茶/品茶、苗寨文化、餐饮或民宿承接。
- Java 是业务数据唯一写入口；Python AI 服务通过受控接口查询资源并生成待确认预约。
- 所有未核验的资源、价格、库存和图片是演示数据。
- 不包含真实支付、微信正式登录、真实库存、真机公网访问和生产部署。

## 本机配置提醒

模型和观测能力由用户在本机 `agent-service/.env` 提供配置；仓库不保存任何 API Key。未配置时，AI 页面应明确呈现降级提示，资源、订单和后台演示仍可继续。
